# Security

Report vulnerabilities in Palside privately to [palside@pm.me](mailto:palside@pm.me). Please do not include vulnerability details in public issues or pull requests. Reports about the service, website or contracts are welcome at the same address, even though the service and website code is not in this repository.

Include:

- The affected component and version, tag or commit.
- Reproduction steps and a minimal proof of concept, if available.
- The expected and actual behavior, and the potential impact.
- Relevant logs or screenshots with credentials, keys, and personal data removed.

Use test accounts and test assets for reproductions. Never send recovery phrases, private keys, passwords, device tokens, private environment files, or other users' chat content. A transaction hash and redacted request or error details are preferable to signing material.

Data, permissions and retention are described on [palside.xyz/privacy](https://palside.xyz/privacy), and contract addresses on [palside.xyz/security](https://palside.xyz/security).

The security contact is also published in [security.txt](https://palside.xyz/.well-known/security.txt).

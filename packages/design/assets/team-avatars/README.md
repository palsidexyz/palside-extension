# Squad avatars

24 group illustrations for squads: 8 character pairs, 6 portraits, 6 chats and 4 rides. Personal avatars live in [`../avatars/`](../avatars/).

- 256×256 opaque sRGB WebP, each under 20,000 bytes, named `team-avatar-{id}.webp`.
- Full-bleed square backgrounds; circular or rounded crops are applied by the UI.
- `sources.json` records each ID, file name, byte length and SHA-256.
- These tracked files are the source; `public/team-avatars/` is generated by the asset sync script.

| Series | IDs |
| --- | --- |
| Character pairs | frog-ghost, robot-duo, cat-duo, blob-trio, mushroom-pals, cool-birds, ghost-high-five, monster-stack |
| Portraits | portrait-classics, portrait-cosmic, portrait-cozy, portrait-nature, portrait-playful, portrait-mischief |
| Chats | chat-classics, chat-cosmic, chat-cozy, chat-night, chat-odd, chat-garden |
| Rides | ride-boat, ride-spaceship, ride-camper, ride-skateboard |

A squad gets its default avatar from its stable ID; a saved custom avatar takes precedence. Options and translation keys are in `apps/extension/src/features/palside/teams/default-team-avatar.ts`.

```sh
node scripts/sync-site-assets.mjs
node --experimental-strip-types --test tests/default-team-avatar.test.mjs tests/default-avatar.test.mjs
```

The tests check the full list, stable assignment, size, opacity, byte length and SHA-256.
